Class I peptides have an N-terminal Arg with the consensus sequence RXLPPZP (Z represents Leu for the Src SH3 domain [Src SH3] and Arg for PI3K SH3), whereas class II peptides have a C-terminal Arg with the con- sensus sequence XPPLPXR. Phage display libraries have also been used to define the minimal core recognition motifs for Sre, Fyn, Lyn, Abl, and PI3K domains as well as the additional flanking sequences preferred by each individual SH3 domain (1, 17, 18, 21).
