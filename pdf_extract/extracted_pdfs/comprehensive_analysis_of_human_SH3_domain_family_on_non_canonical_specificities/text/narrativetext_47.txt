We organized the 154 binding specificities for 115 SH3 domains into nine classes based on similarities in peptide-binding prefer- ences. To aid interpretation, we divided all domains within each class based on peptide-binding similarities represented by PWM logos (Figures 2 and 3). We followed established nomenclature to define class | (Figure 1A) and class II (Figure 1B) domains as those recognizing peptides containing the PxxP core and an R/K residue either N- or C-terminal to the core, respectively. Do- mains able to recognize both class | and class II peptides were placed in class I/II (Figure 2C). We identified 25 domains showing alternative class I-like or class II-like specificities that we group- ed in six additional classes (Ill to VIII). Specificities where the proximal Pro residue was not required were classified as class III (“°RxxxxxP%(+), three domains, Figure 3A) or class IV PxxxxR**(—), three domains, Figure 3B) if they resembled class | or Il, respectively. Conversely, if the distal Pro residue was not required, the specificities were classified as class V (SRxxP°xxx"S(4), nine domains, Figure 3C) or class VI (-®xxxP°xR*?(—), three domains, Figure 3D) if they resembled class | or Il, respectively. Class II-like domains that substituted the flanking Arg residue with a Lys residue inserted within the PxxP core were classified as class VII (PxK**P**(—), two do- mains, Figure 3E). We assumed that class VII peptides bound in a minus orientation because we were only able to find this positively charged residue embedded in the PxxP core for class II domains, °PxK*?P**xR*°(—), and because this orienta- tion is observed in all known structures of SH3 domains in complex with a peptide conforming to a °Px[R/K]**P**(—) motif (Harkiolaki et al., 2009; Zhao et al., 2014).
