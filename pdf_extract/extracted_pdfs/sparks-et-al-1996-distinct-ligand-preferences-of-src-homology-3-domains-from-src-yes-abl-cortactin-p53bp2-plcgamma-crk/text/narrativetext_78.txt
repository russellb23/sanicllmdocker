The Sre SH3 domain is capable of binding both class I and class II peptides (19). Although class I peptides predominate the population of Src SH3 ligands selected from the PXXP library, one clone conforms well to the class II consensus (Fig. 1). Previously, we (12) and others (14) have isolated class IT Src SH3 ligands sharing the consensus PPYPPR. Similarly, whereas the Grb2 N SH3 domain has been shown to bind peptides from SOS with the class II consensus sequence PPYPPR (5), we have isolated Grb2 N SH3 ligands that conform to the class I consensus (Table 1). Thus, both the Src and the Grb2 N SH3 domains apparently have the capacity to bind both class I and class II peptide ligands.
