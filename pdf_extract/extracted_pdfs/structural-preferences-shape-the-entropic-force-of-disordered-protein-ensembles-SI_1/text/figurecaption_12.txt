Figure S2. Sequence features correlated with the entropic force strength. The entropic force strength is plotted vs several sequence features. Unless stated otherwise, all sequence features are calculated using the localCIDER python package. (A) K: a metric for mixing of charged amino acids'® (B) FCR: fraction of charged residues, (C) NCPR: net charge per residue, (D) Cluster_ILVAM: hydrophobic amino acid mixing calculated using the same algorithm as K, (E) Cluster_QNSTH: polar amino acid mixing calculated using the same algorithm as K, (F) Cluster_YFW, aromatic amino acid mixing calculated using the same algorithm as kK. (G) SCD: sequence charge decoration’? (H) SHD: sequence hydropathy decoration?" (Il) SHD vs sequence length shows a strong correlation with the sequence length. This may explain at least some of the correlation with entropic force, which is also shown to correlate with sequence length (Fig. 5A).
